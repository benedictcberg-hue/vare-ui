Mit dem privaten Korpus verbinden

Diese Seite ist öffentlich und enthält keine Messwerte — weder deine Marken noch Aufnahmen noch Auswertungen. Sie liest korpus.json aus dem privaten Repo mit deinem eigenen GitHub-Token, und zwar nur lesend. Erst danach erscheint die Oberfläche.

Alles Weitere bleibt ohnehin auf diesem Gerät: Aufnahmen, Chronik und Export liegen im Browserspeicher. Es geht nichts an GitHub zurück.

Token anlegen (einmalig)
  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → nur .
  3. Permissions → Repository permissions → Contents: Read-only. Sonst nichts.
  4. Token hier einfügen und „Verbinden“.

Schreibrechte braucht die Seite nicht. Ein Token mit mehr Rechten als nötig ist das einzige Risiko, das diese Hülle überhaupt hat.

Aus file:// heraus ist das Mikrofon gesperrt und ein gemerktes Token wäre für andere lokale Seiten lesbar. Im Ordner starten: python -m http.server 8000.

Mikrofon ist aus file:// gesperrt. Im Ordner dieser Datei starten: python -m http.server 8000, dann http://localhost:8000 öffnen. Die Chronik ist auch hier lesbar; aufnehmen geht nur über http://localhost oder https.
Die Chronik liegt nur in diesem Browser unter dieser Adresse (). Nichts verlässt das Gerät. Andere Adresse oder anderer Browser = andere Chronik; Übertragung per JSON-Sicherung.
