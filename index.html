Aufnahme Chronik

Mit dem privaten Korpus verbinden

Diese Seite ist öffentlich und enthält keine Messwerte — weder deine Marken noch Aufnahmen noch Auswertungen. Sie liest korpus.json aus dem privaten Repo mit deinem eigenen GitHub-Token. Erst danach erscheint die Oberfläche.

Aufnahmen, Chronik und Export bleiben auf diesem Gerät im Browserspeicher. Zurück ins private Repo geht nur eins: nach jeder Kalibrierung eine kleine Datei mit ihren Messwerten (data/input/, ohne Gerätename, ohne Audio).

Token anlegen (einmalig)
  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → nur .
  3. Permissions → Repository permissions → Contents: Read and write. Sonst nichts.
  4. Token hier einfügen und „Verbinden“.

Geschrieben wird nur die Ablage der Kalibrierung nach data/input/. Mit „Read-only“ läuft alles andere weiter; die Kalibrierungen warten dann im Browser. Gib dem Token kein weiteres Repo und keine weitere Berechtigung.

Aus file:// heraus ist das Mikrofon gesperrt und ein gemerktes Token wäre für andere lokale Seiten lesbar. Im Ordner starten: python -m http.server 8000.

Mikrofon ist aus file:// gesperrt. Im Ordner dieser Datei starten: python -m http.server 8000, dann http://localhost:8000 öffnen. Die Chronik ist auch hier lesbar; aufnehmen geht nur über http://localhost oder https.

    Wozu diese Angaben?

    Einsingen und Pausen verändern die Stimme. Diese vier Angaben entscheiden, ob zwei Takes überhaupt vergleichbar sind. Sie werden mitgeschrieben, nicht geschätzt: was hier leer bleibt, steht in der CSV als −99 (Zahl) oder als leere Zelle (Text).

    Sitzung – · nächster Take ist Nummer – · Pause seit dem letzten Take –
    Wie Pause und Nummer gezählt werden
    Die Pause wird aus der Uhrzeit des letzten Takes gerechnet und läuft mit — sie wird im Moment des Take-Starts festgehalten. Die Take-Position zählt innerhalb dieser Sitzung fortlaufend; die Nummer eines gelöschten Takes wird nicht neu vergeben. „Neue Sitzung beginnen“ setzt sie auf 1 zurück und verlangt eine neue Kalibrierung. Die Minuten seit Einsingbeginn laufen mit: eingetragen wird der Stand im Moment der Eingabe, jeder Take rechnet die Minute seines Starts. Liegen letzte Eingabe und letzter Take über drei Stunden zurück, werden die Einsing-Angaben geleert — das ist dann eine andere Übungseinheit.
